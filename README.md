# Automated Cloud Security & DevSecOps Vulnerability Pipeline

## Project Overview

An automated security pipeline designed to detect
vulnerabilities in source code, dependencies,
Docker containers, and cloud infrastructure.

## Technologies

- Kali Linux
- Python
- Git and GitHub
- Docker
- Jenkins
- SonarQube
- Gitleaks
- Trivy
- Checkov
- AWS
- Grafana

## Project Goals

1. Automate source code security scanning.
2. Detect exposed secrets.
3. Identify vulnerable dependencies.
4. Scan Docker images.
5. Detect cloud infrastructure misconfigurations.
6. Implement automated security gates.
7. Generate vulnerability reports.
